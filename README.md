# Інтерактивні лабораторні роботи

Інтерактивні навчальні матеріали з дисципліни  
**«Енергоефективні технології споживання електричної енергії»**.

Проєкт містить дистанційні лабораторні роботи з теоретичними матеріалами, віртуальними стендами, інтерактивними дослідами, розрахунками, графіками, контрольними питаннями та формуванням звітів.

## Онлайн-версія

https://bii-ee.github.io/eetsee-labs/

## Лабораторні роботи

- **ЛР №5** — дослідження енергетичних характеристик електродного нагрівача. Матеріали готуються.
- **ЛР №6** — дослідження енергетичних характеристик печей опору з тиристорними джерелами живлення.
- **ЛР №7** — дослідження параметрів роботи побутових двоконфоркових електроплит із біметалевим регулятором потужності.
- **ЛР №8** — дослідження параметрів роботи побутових індукційних плит.

## Можливості

Лабораторні роботи передбачають:

- послідовне проходження етапів роботи;
- інтерактивні віртуальні стенди;
- проведення модельованих експериментів;
- автоматичне збереження результатів у браузері;
- виконання розрахунків;
- побудову графіків;
- формулювання висновків;
- контрольні питання;
- автоматичне формування звіту;
- друк або збереження звіту у PDF.
